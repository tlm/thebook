# Fusion

This entry applies to operating Autodesk Fusion through its MCP server to
inspect, create, or change designs. Use the harness routing convention for
the guidance below.

Treat this guidance as shared defaults. Explicit, applicable instructions
from the user or the consuming project take precedence where they specify
different requirements.

## Guidance

| Guidance | Applies to | Read policy |
| --- | --- | --- |
| [Operation](operation.md) | All work in Fusion, including inspection | Default |
| [Modelling](modelling.md) | Creating or changing geometry, sketches, components, or parameters | Conditional |
| [Verification](verification.md) | Changing a design, before reporting the work complete | Conditional |
