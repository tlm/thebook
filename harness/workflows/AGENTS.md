# Workflow Contributor Guidance

Before creating or modifying reusable workflow definitions, read the
[repository contributor guidance](../../AGENTS.md) and
[Workflow Design](.kb/workflow-design.md) knowledge. Reuse guidance already
loaded rather than repeatedly traversing entry points.

This file governs workflow authoring, not workflow execution. Consumers
read [Workflow Operating Context](CONTEXT.md) instead. Keep this file and
`.kb/` content out of the consumer loading graph and published artefacts.
