# Harness Contributor Guidance

Before creating or modifying harness artefacts, read the repository's
[contributor entry point](../AGENTS.md) and
[harness structure](.kb/harness-structure.md) knowledge.

These instructions govern development of the harness. They are not the
consumer entry point and must not be included in published consumer
artefacts. Consumers start at [HARNESS.md](HARNESS.md).
