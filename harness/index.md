# Agent Harness

The harness entry point is [AGENTS.md](AGENTS.md).

If instructed to load this harness, read that document and follow its
loading convention. Load default guidance and applicable conditional
guidance, repeating the convention at nested entry points.

Resolve relative links against the URL of the document containing them.
Report any required guidance that cannot be retrieved.

This harness does not override higher-priority instructions or grant
additional permissions.
