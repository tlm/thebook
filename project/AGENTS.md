# Project Guidance

This guidance applies when working within a consuming project. The project
is the one being worked on, not the directory or website hosting this
harness.

- Before working in a project, check for an `AGENTS.md` file at its root.
  If present, read it and follow its applicable guidance and loading
  instructions. If the host has already supplied its current contents,
  use that context rather than reading it again.
- When working in a subdirectory, also follow applicable nested
  `AGENTS.md` files according to the host's scoping rules. Do not load
  unrelated nested guidance indiscriminately.
- Reuse guidance already loaded if project instructions link back to this
  harness or another entry point already followed. Do not repeatedly
  traverse a loading cycle. Reassess applicability when the work changes.
- Do not create an `AGENTS.md` file merely because none exists. Report
  guidance that exists but cannot be read, and follow the harness's
  requirements for handling unavailable required guidance.
- Project guidance remains subject to the host's instruction hierarchy.
  Reading it does not grant permissions or override higher-priority
  instructions.
